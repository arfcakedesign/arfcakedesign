# Arf Cake Design — web sitesi

Ataşehir, İstanbul’daki butik pasta atölyesi Arf Cake Design’ın tek sayfalık web sitesi.

## GitHub Pages ile yayınlama
1. GitHub’da yeni bir depo (repository) oluşturun ve bu klasördeki tüm dosyaları yükleyin.
2. Depoda **Settings → Pages** bölümüne gidin; *Source* olarak `main` dalını ve `/ (root)` klasörünü seçin.
3. Birkaç dakika sonra site `https://arfcakedesign.github.io/arfcakedesign/` adresinde yayında olur.

## Yayın adresi
Site adresi dosyalarda `https://arfcakedesign.github.io/arfcakedesign/` olarak ayarlıdır. Kendi alan adınızı (ör. arfcakedesign.com) bağlarsanız
`index.html`, `robots.txt`, `sitemap.xml` ve `llms.txt` içindeki bu adresi yeni adresle değiştirin.

## Yayından sonra
- **Google Search Console**: siteyi ekleyin ve `sitemap.xml` adresini gönderin.
- **Google İşletme Profili**: Ataşehir konumlu bir işletme profili açıp web sitesi olarak bu adresi ekleyin; yerel aramalarda en büyük etkiyi bu yapar.
- Instagram profilindeki bağlantıya site adresini ekleyin.

## Dosyalar
- `index.html` — site
- `images/` — fotoğraflar ve paylaşım görseli (`og-image.jpg`)
- `favicon.svg`, `apple-touch-icon.png` — tarayıcı ve telefon simgeleri
- `robots.txt`, `sitemap.xml` — arama motorları için
- `llms.txt` — ChatGPT, Claude, Perplexity gibi yapay zekâ asistanları için işletme özeti
- `404.html` — bulunamayan sayfa
